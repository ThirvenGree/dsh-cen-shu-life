# 岑舒跨入口联动

## 当前范围

- Cosplay 本身全局生效；工具与技能按任务动态筛选，权限不变。
- 岑舒的桌面根会话出现真实用户消息后，自动加入生活插件共用的绑定表。已有对话在载入时识别。共享生活、情境、心情、动态上下文预算、审核记忆写回、更正/遗忘、问题回忆和浏览经历。
- 只识别当前启用且与生活角色匹配的 Cosplay；子代理、预登记的测试/私人会话、测试工作区、正式生活工作会话不自动加入聊天绑定。切换角色后移除自动绑定，手动绑定保留。
- 自动绑定保存在 config.json 的 desktopSessionIds，同时加入 sessionIds 供现有适配读取。设置页显示当前数量与边界。不会追溯提炼旧聊天。
- 鱼的心情通过动态绑定共享已有 moodSlot，不新建分数。显式绑定在其他心情槽的会话不会被抢占。
- QQ/桌面回复和 Pet 文字、实时语音输出经过 Argon 语句编辑；B站和抖音另保留平台外发安全审核。
- Pet 延续只读共享：普通输入只进 Pet 自身历史，不更新全局心情、活动或长期记忆。明确的更正/遗忘命令仍走预览与审核。
- 生活会话仍由主动进行负责，执行与审核隔离不变。桌面交谈不会改变主动接管的主角色编号，也不会启用第二套后台行动。

## 短答与记忆

桌面短答以当前用户消息 ID 定位，只关联它之前最近的助手正文；跨过另一条真实用户消息就停止。还没有持久化、缺 ID 或来源为内部插件时，不猜测回答对象，不按相同文字配对。写回前仍需模型审核。所有记忆插件的自动采集守卫实时读取同一绑定表，召回不受影响。

## 保持渠道专用

QQ消息编号、轻量记忆、联系人、发送冷却和发送回执继续属于QQ；网页评论/私信的隐私审核继续属于对应平台。跨入口共享角色能力，不把桌面回复自动发到QQ，也不把第三方消息当成青枔来信。
