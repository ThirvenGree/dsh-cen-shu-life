# 动态请求上下文

生活、独处与主动进行仍共享模型规划。此版本把最终请求投影接到 DSH 的原生 adapter 边界：Cordis 的 `llm/stream` 继续接收冻结的原请求，所有监听器和已准备的 provider 注册正常执行。投影只生成请求副本，不写会话事件、原始工具结果或记忆库。

## 当前状态与历史资料

DSH 官方 `runtime-context` 完整快照明确声明它取代之前的快照。旧快照进入有来源、有版本的历史候选，不继续伪装成当前状态。模型决定本轮仍要展开哪些资料，未展开的原文可由 `censhu_context_recall` 取回。真实来信、工具调用配对、身份、用户要求和权限规则不按普通资料删减。

外来来源只有符合明确的纯资料协议才参与预算；未知结构保留。最终请求重新核对原文与版本，以免 DSH `refreshContext()` 恢复了之前未被模型选中的资料。新版本或未经过本轮规划的内容先保留，不套用旧决定。

## 工具按需载入

Gemini 根据本轮任务选择需要完整定义的工具。原工具注册表、工具参数校验、权限守卫、执行登记和发送审核全部保持原样。

`censhu_tool_catalog` 是只读目录：分页查询工具，或用 `load` 指定名称，让下一次模型步骤带上原始完整定义。载入不是执行，不存在绕过原权限的通用执行工具。已在历史中使用、明确加载及 `toolChoice` 指定的工具定义保留。规划失败时保留原定义。

## 大结果按需展开

模型可以保留全文、选择准确字符区间，或仅保留精确原文入口。图片、音频和其他非文本块不裁剪，错误不裁剪。动作回执及部分成功/失败不能被当作普通网页正文处理。只有本地原文快照保存成功后，才允许使用原文指针。

`censhu_tool_result_read` 按当前会话、内容版本、部分编号和偏移读取原文，不重新执行工具。已经读过的范围会反馈给规划器。主模型仍可继续取回原文与原有媒体。工具结果处理和历史压缩分工不同，不另起压缩引擎，也不改写 billion-context 的压缩状态。

## 预算与观察

设置页显示模型配额、采用量、理由、最终请求估算及提供方实际输入回执。历史页面的累计字符估算不是本轮发送量；无提供方回执时不宣称实际 token 节省。

同一回合尽量复用已确认决定及完整定义顺序，减少重复规划和无意义的缓存前缀变动。输入规模、模型超时、原文存储失败会明确记录，回退保留资料；窗口与回复预留继续由程序和既有压缩流程保护。归档、释放、结束回合及插件重载都会使旧的在途决定失效。

设置页刷新是只读操作，不启动模型判断。新调用在外部模型监控中标注为“上下文 · 动态工具定义与结果呈现”。

## 验证

`test/request-context.test.js` 覆盖工具发现/加载、错误与媒体保护、精确读回、回合与卸载失效、模型/存储故障；`test/context-budget-foreign.test.js` 覆盖外来来源和真实 runtime 快照。`test/request-host.test.js` 对宿主接线进行隔离集成验证，不创建正式记忆或发送 QQ。

agency 的 `request-projection-runtime.test.js` 可在提供 `DSH_RUNTIME_ROOT` 时验证当前安装的真实 Cordis 与 LlmRuntime：冻结输入、prepared provider 绑定、下游监听器、共享注册与热重载均不被绕过。

2026-11-04 本机验证覆盖真实宿主的三种工具更新模式，使用隔离资料和模拟 provider，无正式记忆写入。另做的一次真实 Gemini 请求返回 HTTP 402（项目预付余额不足），已经验证失败后保留原文；尚不能据此声称真实模型已完成选择或实际节省了输入 token。
