# 岑舒定性心情与行动联动验收

日期：2026-11-05。本机源码链接安装；未发布 GitHub。

## 实现
- 鱼的心情直接调用 Gemini 3.8 Flash，生成自由命名的并存感受、自然语言强弱、对象、缘由、拉扯、表达/行动倾向、有效期和复看时机。不再调用岑舒旧数值判断，也不按固定七维或总分驱动图标。
- 生活、独处、主动进行、主动搭话以及经共享服务读取背景的浏览、视频和 Pet 使用定性感受。Pet 继续只读。
- 主动进行的计划、私人阅读、普通工具回执和反思进入经历审核。已有 B站、抖音、浏览器专用回执不重复入队；轮询和内部工具调用登记不当作完成。
- 稳定来源编号持久化去重；独处对同一事件的新感受仍须通过审核且只提交一次。旧数值字段仅为兼容保留，其他未绑定角色维持上游逻辑。
- 设置页与挂饰去除岑舒分数；独处设置去除不再适用的数值配额；联动页显示定性读取回执和主动行动入口。
