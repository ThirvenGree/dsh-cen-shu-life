# dsh-cen-shu-life

岑舒的独立生活插件。按《岑舒_第七版》维护日程、轻量随机事件与心情行为，不修改 DSH 核心，不自己发送消息。

## 安装

需要 Node 22+ 和 DSH Desktop。当前实测 DSH 0.2.1-rc.3、dsh-feiyu-mood 0.7.6、dsh-speak-up 0.2.6。

```powershell
git clone https://github.com/ThirvenGree/dsh-cen-shu-life.git
cd dsh-cen-shu-life
node scripts/install.mjs "你的DSH家目录/profiles/desktop" "你的岑舒会话ID"
```

重启 DSH。设置侧栏打开「岑舒生活」，设置目标会话与心情记录键。修改设置立即生效；安装、更新宿主代码需重启。默认不绑定任何会话，其他角色不受影响。`DSH_HOME` 优先，否则使用用户家目录下 `.dsh`。

## 职责

- `dsh-feiyu-mood`：判断、保存和衰减心情。
- `dsh-speak-up` / 现有 QQ bridge：继续各自触发主动聊天。
- 本插件：日程、事件、行为映射、上下文，不调用模型做心情判断、不直接发送。

实际安装版本的 `/dsh-feiyu-mood/state` 调用会执行 `getState(... persist:true)`，不是无副作用的跨插件读取。因此采用只读 v2 文件适配器；验证版本、七维数值与明确会话绑定，读取失败保持平常并记日志。文件更新异常不会写回原心情。不读取或覆盖整份聊天历史。

## 插件内设定与工具联动（1.1）

人物背景、一般说话方式、关系边界、每周倾向及工具协作规则保存在本地 `profile.json`；11 种模式的表达规则保存在 `config.json.modeRules`。首次使用的默认规则来自 `data/behaviors.json`，不是测试消息中的长提示词。DSH 设置 → 岑舒生活，可在现代化面板中直接编辑并保存，下一轮立即读取。原始角色卡保持只读。

`censhu_life_context` 是绑定角色专用的状态读取工具；每轮也通过动态上下文自动读取，不依赖模型记得调用。工具仍按已有配置工作：BrowserSkill 路由、文件/图片/表情预览、语音、生图和记忆不会被生活模式禁用。心情只调表达，明确任务仍需完整完成。API 密钥仍在原环境变量中，不复制到本插件。

测试会话通过 `/simulate/session` 临时挂载隔离的模拟上下文，聊天里只传真实测试发言，不贴整段角色设定。模拟绑定只存内存，20 分钟过期，禁止覆盖正式角色会话，可主动清除。

## 功能

- 上海时区日程，可修改；工作日与周末分开，春节按农历判断。
- 17 个 JSON 事件模板：档案工作、旧书、纪录片、整理、感冒、修路、家庭电话、天气、季节、工资及出行。每个模板含条件、权重、阶段、持续时间、冷却与重复限制。
- 默认每 30 分钟一次随机检查，概率 0.22，每日最多 2 件、同时最多 2 件；可以没有新事。离线不补造大量事件，重启只推进已存在事件。
- 天气必须手动确认有效期；工资日未配置不触发；出行默认关闭。不会自动查询现实天气、工资或出行。
- 11 种行为：平常、有点高兴、很高兴、低落、心软、难为情、吃醋后收声、累、烦、被惹到、慌。综合可信心情、基线差、七维变化、日程与真实新消息；低分不等于烦，甜蜜不自动等于难为情。
- 关心优先、感情场景优先、最短维持、恢复过渡与最长有效期。阈值、持续时间、各模式具体规则可配置。
- 每轮重新读取有效心情，使用 DSH `systemPrompt.context`，只注入绑定会话。心情判断在轮末完成，下一次模型请求使用新结果，不回写已生成回复。
- QQ 初始快照及等消息工具返回的新消息参与场景判断；成功发送及 DSH 正文参与提及记录，避免连轮重复。
- 设置页支持开关、绑定、时区、数量、概率、分类、阈值、行为文本、状态预览、手动新增/结束/重置、完全隔离的模拟测试。

事件属于角色生活模拟，不是用户现实经历。日程只是倾向；未记录的书名、影片结局、电话细节不当事实。事实约束不能保证模型每次生成都完全遵守，因此提供实际回复验收与样例。

## 本地文件

`<DSH_HOME>/cen-shu-life/` 下保存 `config.json`、`profile.json`、`events.json`、`state.json`、`history.json`、`diag.log`。JSON 均有版本号，原子替换；损坏配置保留备份，恢复默认且不自动绑定。日志有大小上限，历史有数量上限。原始人物卡和心情文件始终只读。

`modeRules` 为模式键到行为文字的 JSON 映射（如 `{"low":"回复变短……"}`），空对象使用默认规则。天气可通过配置接口设置 `weather: {kind:"rain", expiresAt:毫秒时间戳}`；也支持 `humid/hot/cold`。天气信息不自动更新。

## 接口

接口挂载在同一 DSH 本地回环服务。实测当前版本的插件路由可在本机直接访问，不要求 DSH 会话 Cookie；修改接口检查同源，返回内容不包含密钥或聊天令牌。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/dsh-cen-shu-life/settings` | 独立设置页面 |
| GET | `/dsh-cen-shu-life/state` | 状态、心情读取结果、上下文与模板 |
| GET/POST | `/dsh-cen-shu-life/config` | 读取/保存设置 |
| GET/POST | `/dsh-cen-shu-life/profile` | 读取/保存人物与工具联动设定 |
| POST | `/dsh-cen-shu-life/simulate/session` | 独立测试会话的临时模拟绑定/清除 |
| POST | `/dsh-cen-shu-life/event` | `{action:"add",templateId}`、`{action:"end",id}`、`{action:"reset"}` |
| POST | `/dsh-cen-shu-life/simulate` | 独立心情、场景、日程与事件模拟，不修改真实状态 |

卸载时从 profile 的 dependencies、bundles 移除本插件并重启；自己的数据可保留，永不删除原始角色卡或心情数据。恢复安装可复用旧事件。

## 验证

```sh
npm test
npm run check
```

没有第三方运行依赖。`test/` 覆盖所有模式、优先级、心情异常、会话隔离、模式恢复、事件推进/冷却/数量限制、重启、模拟隔离、时区、农历和真实消息提取。实际回复对照见 `docs/acceptance.md`。该报告只包含独立模拟场景，不含实际 QQ 聊天、密钥或会话令牌。

## 与既有本机联动

本机 `dsh-censhu-policy` 辅助层已适配：启用生活模块时不再叠加旧行为上下文，两个主动触发器保留共享冷却，读取生活模块的模式；bridge 控制台显示生活事件并链接此设置页。新安装若没有该辅助层，不需要此适配；正常动态上下文仍生效。
